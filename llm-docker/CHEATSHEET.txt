📋 INITIAL SETUP (One Time)
─────────────────────────────────────────────────────────────────
./setup.sh                          # Run first-time setup

🚀 START SERVICES
─────────────────────────────────────────────────────────────────
./scripts/start-ollama.sh           # Start Ollama (recommended)  :11434
./scripts/start-forge.sh            # Start Stable Diffusion      :7860
./scripts/start-vllm.sh [model]     # Start vLLM
./scripts/start-tgi.sh [model]      # Start TGI
./scripts/stop-all.sh               # Stop everything
docker compose -f docker-compose.forge.yml down    # Stop Forge

🎨 STABLE DIFFUSION (FORGE)
─────────────────────────────────────────────────────────────────
Web UI:  http://localhost:7860
API:     http://localhost:7860/docs

# Checkpoints go here (then hit 🔄 refresh in the UI):
/mnt/llm-models/stable-diffusion/models/Stable-diffusion/

# Installed:  sd_xl_base_1.0 (~8GB VRAM) | flux1-schnell-fp8 (~17GB VRAM)

# SDXL settings:  1024x1024, DPM++ 2M Karras, 25-30 steps, CFG 6-7
# FLUX settings:  1024x1024, Euler+Simple, 4 steps, CFG 1.0  (4 steps! more = worse)

⚠️  GPU IS SHARED — VRAM ADDS UP (24GB total)
─────────────────────────────────────────────────────────────────
docker exec ollama ollama stop <model>    # Free VRAM before FLUX runs
nvidia-smi --query-compute-apps=pid,used_memory,name --format=csv

# SDXL (8GB) + 14B LLM (9GB)  = OK
# FLUX (17GB) + 32B LLM (19GB) = OOM!
# Ollama auto-unloads idle models after 5 min.

📦 OLLAMA COMMANDS (Inside Container)
─────────────────────────────────────────────────────────────────
docker exec -it ollama ollama list
docker exec -it ollama ollama pull llama3.2:3b
docker exec -it ollama ollama run llama3.2:3b
docker exec -it ollama ollama rm llama3.2:3b

⚡ QUICK DOWNLOADS
─────────────────────────────────────────────────────────────────
./scripts/batch-pull-models.sh small    # 3-8B models
./scripts/batch-pull-models.sh medium   # 14B Q4 models
./scripts/batch-pull-models.sh large    # 70B Q2 models

🧪 TESTING & BENCHMARKING
─────────────────────────────────────────────────────────────────
./scripts/test-model.sh ollama "Hello!"        # Quick test
./scripts/benchmark.sh ollama 10               # Single model benchmark
./scripts/run-full-benchmark.sh                # Full automated benchmark (34 models)
./scripts/run-full-benchmark.sh --skip-pull -y # Quick benchmark (no downloads)

📊 MONITORING
─────────────────────────────────────────────────────────────────
docker compose ps                   # Service status
docker stats                        # Resource usage
watch -n 1 nvidia-smi              # GPU monitoring
docker compose logs ollama         # View logs

🎯 RECOMMENDED TESTING ORDER
─────────────────────────────────────────────────────────────────
1. Start Ollama:     ./scripts/start-ollama.sh
2. Pull small model: docker exec -it ollama ollama pull llama3.2:3b
3. Test it:          docker exec -it ollama ollama run llama3.2:3b
4. Try larger:       docker exec -it ollama ollama pull llama3.1:8b-q4
5. Compare:          ./scripts/benchmark.sh ollama 10

💡 POPULAR MODELS FOR RTX 3090 (24GB)
─────────────────────────────────────────────────────────────────
Small (Fast):
  llama3.2:3b          ~6 GB     Good for testing
  llama3.1:8b-q4       ~5 GB     Balanced quality/speed

Medium (Quality):
  llama3.1:8b          ~16 GB    Full precision 8B
  qwen2.5:14b-q4       ~8 GB     Strong reasoning

Large (Max Quality):
  llama3.1:70b-q2      ~19 GB    Aggressive quant, slow
  llama3.1:70b-q3      ~24 GB    Better quality (tight fit)

🆘 COMMON ISSUES
─────────────────────────────────────────────────────────────────
OOM Error:    Use smaller model or lower quantization
Port in use:  ./scripts/stop-all.sh first
Slow:         Check with nvidia-smi for GPU usage
No GPU:       Verify: docker run --rm --gpus all nvidia/cuda:12.1.0-base-ubuntu22.04 nvidia-smi
