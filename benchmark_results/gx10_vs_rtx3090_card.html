NVIDIA GB10 · ASUS GX10 · local LLM benchmark

A 120B model that outruns a 32B one

On the GB10's unified memory (~273 GB/s), token speed is set by how many parameters get read per token — not the total. So MoE & hybrid models crush dense ones of the same size, and a 120B mixture-of-experts beats a 32B dense model outright. On this hardware, architecture beats size.
